# Cotação do Dólar

Site simples que mostra a cotação atual do dólar usando a API da AwesomeAPI.

Feito com HTML, CSS, JavaScript e Node.js + Express.

## Como rodar localmente

1. Instale as dependências:
```
npm install
```

2. Rode o servidor:
```
node server.js
```

3. Abra no navegador: http://localhost:3000
